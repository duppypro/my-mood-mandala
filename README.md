# my-mood-mandala

Create ephemeral art that vibes with your mood of the moment, the day, or the week.

Draw with a sand-textured brush and your strokes mirror into a mandala; the symmetry selector picks
how. Sign in with Google and your strokes sync to your account through Firestore.

Started as a Google AI Studio export.

## Run locally

Needs [bun](https://bun.sh).

```sh
bun install
bun run dev      # Vite on port 3000
bun run build    # → dist/
bun run lint     # typecheck
```

## Built with

Vite · TypeScript · Tailwind · D3 · Firebase Auth + Firestore
